# PC Monitor

Веб-панель для мониторинга и удалённого управления Windows-ПК с телефона: загрузка CPU/RAM/дисков/сети в реальном времени, список процессов с завершением, запуск программ/скриптов, выключение/перезагрузка/сон/блокировка.

Работает как обычный Node.js-сервер, который запускается на самом ПК. Открываете сайт в браузере телефона (локально по Wi-Fi или через интернет с помощью Tailscale) — получаете дашборд.

## Возможности

- **Мониторинг в реальном времени** (обновление раз в 2 сек через WebSocket): загрузка CPU (в т.ч. по ядрам), температура, память, диски, сеть, батарея, аптайм.
- **Процессы**: список с сортировкой по загрузке CPU, поиск, завершение процесса (`taskkill /F`).
- **Запуск программ/скриптов**: быстрые кнопки (настраиваются в `server/config/quickLaunch.json`) + произвольная команда (в фоне или с ожиданием вывода).
- **Питание**: выключение, перезагрузка, сон, блокировка экрана, выход из системы, отмена запланированного выключения.
- **Авторизация**: логин/пароль (bcrypt) + JWT-сессия, rate-limit на вход, опциональный allowlist по IP.

## Требования

- Windows 10/11 (сервер также умеет работать на Linux/macOS с ограниченным набором команд, но разрабатывался под Windows).
- [Node.js](https://nodejs.org/) 18 или новее.

## Установка

```bash
git clone <адрес репозитория>
cd monitoring-pc
npm install
```

Скопируйте `.env.example` в `.env`:

```bash
copy .env.example .env
```

Сгенерируйте хэш пароля администратора:

```bash
npm run create-user
```

Скрипт спросит пароль и выведет строку вида `ADMIN_PASSWORD_HASH=...` — вставьте её в `.env`.

Сгенерируйте секрет для JWT и тоже впишите в `.env` (переменная `JWT_SECRET`):

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

Проверьте/поменяйте `ADMIN_USERNAME` и `PORT` в `.env` при необходимости.

## Запуск

```bash
npm start
```

Откройте `http://localhost:3000` в браузере — увидите экран входа.

Чтобы открыть с телефона в домашней сети: узнайте IP ПК (`ipconfig`, обычно `192.168.х.х`) и зайдите на телефоне на `http://192.168.х.х:3000`. Возможно потребуется разрешить порт 3000 в брандмауэре Windows (Windows Defender Firewall → Разрешить приложение).

## Доступ из любой точки мира (не только из дома)

Открывать порт напрямую в интернет через проброс портов на роутере **не рекомендуется** — эта панель умеет выключать ПК, завершать процессы и выполнять команды, поэтому она должна быть доступна только вам. Самый простой и безопасный вариант — **Tailscale**:

1. Установите [Tailscale](https://tailscale.com/) на ПК и на телефон, войдите под одним аккаунтом.
2. ПК получит стабильный адрес вида `100.x.x.x` (или `pc-name.tailnet-name.ts.net`).
3. С телефона (даже вне дома) открывайте `http://100.x.x.x:3000` — трафик идёт через зашифрованный VPN-туннель Tailscale, порт наружу не открывается вообще.
4. Дополнительно можно ограничить доступ по IP: впишите Tailscale-адрес телефона в `ALLOWED_IPS` в `.env` (через запятую, если устройств несколько).

Альтернативы: Cloudflare Tunnel, Caddy с TLS + собственным доменом. Их можно поставить перед этим сервером как reverse proxy — сам сервер уже умеет работать по HTTP за прокси (или напрямую по HTTPS, если указать `HTTPS_KEY_PATH`/`HTTPS_CERT_PATH` в `.env`).

## Запуск как службы Windows (чтобы стартовал вместе с ПК)

Проще всего через [NSSM](https://nssm.cc/):

1. Скачайте NSSM, распакуйте.
2. В командной строке от администратора:
   ```
   nssm install PCMonitor
   ```
3. В открывшемся окне укажите:
   - Path: путь к `node.exe` (например, `C:\Program Files\nodejs\node.exe`)
   - Startup directory: папка проекта `monitoring-pc`
   - Arguments: `server/index.js`
4. На вкладке Environment добавьте переменные из вашего `.env` (либо оставьте `.env` — dotenv подхватит его из Startup directory).
5. `nssm start PCMonitor` — сервер запустится и будет автоматически стартовать вместе с Windows.

## Структура проекта

```
server/
  index.js              # точка входа, Express + WebSocket
  config.js              # чтение .env
  middleware/auth.js      # JWT-проверка, allowlist по IP
  routes/                 # auth, system, processes, power, run
  services/                # systemStats, powerControl, processManager, commandRunner
  config/quickLaunch.json  # кнопки быстрого запуска
public/
  index.html, css/, js/    # мобильный дашборд (без сборки, чистый JS)
scripts/create-user.js     # генерация bcrypt-хэша пароля
```

## Безопасность

- Пароль хранится только в виде bcrypt-хэша, сам пароль нигде не сохраняется.
- Токен живёт ограниченное время (`JWT_EXPIRES_IN`, по умолчанию 12 часов).
- На вход действует rate limit (8 попыток за 15 минут с одного IP).
- Эндпоинты `/api/power/*`, `/api/run`, `/api/processes/*/kill` требуют авторизации — без валидного токена ничего сделать нельзя.
- Настоятельно рекомендуется: доступ только через Tailscale (или аналог), а не прямой проброс порта в интернет; сложный пароль; не делиться токеном/ссылкой ни с кем.
