Компьютер под рукой — прямо с телефона

PC Monitor показывает загрузку CPU, памяти, дисков и сети в реальном времени, управляет процессами, запускает программы и умеет выключить или перезагрузить ПК. Сама панель работает на вашем компьютере — эта страница только открывает к ней доступ.

  • Обновление раз в 2 секунды
  • Вход по паролю и JWT-сессии
  • Питание, процессы, запуск программ

Шаг за шагом

Открыть панель своего ПК

Запустите PC Monitor на компьютере и введите адрес его панели. Телефон должен видеть этот адрес — по домашней сети или через Tailscale.

Дома — 192.168.х.х:3000, через Tailscale — 100.х.х.х:3000. Схему http:// можно не писать, добавим сами.

    Запуск на компьютере за три шага

    Нужен Node.js 18 или новее. Команды выполняются в папке проекта на самом ПК — Windows, Linux или macOS.

    1. Установить зависимости

      Скачайте репозиторий и подготовьте проект.

      npm install

    2. Задать пароль

      Скрипт сам создаст .env, запишет хэш пароля и секрет сессии.

      npm run create-user

    3. Запустить сервер

      Панель поднимется на порту 3000. Автозапуск — scripts\install-autostart.ps1.

      npm start

    Доступ откуда угодно — через Tailscale, а не через проброс портов

    Панель умеет выключать компьютер и выполнять команды, поэтому открывать порт в интернет не стоит. Поставьте Tailscale на ПК и на телефон под одним аккаунтом — и заходите на 100.х.х.х:3000 по зашифрованному туннелю. Дополнительно можно ограничить доступ по IP через ALLOWED_IPS.
