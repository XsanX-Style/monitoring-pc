[ 01 ] возможности

Всё, что нужно,
чтобы не вставать к компьютеру

01

Мониторинг в реальном времени

Загрузка CPU и отдельных ядер, температура, память, диски, скорость сети, батарея и аптайм. Данные прилетают по WebSocket каждые две секунды — без перезагрузок страницы.

02

Процессы

Список процессов с сортировкой по загрузке CPU и поиском по имени. Любой можно завершить одним тапом — сервер выполняет taskkill /F с подтверждением.

03

Запуск программ и скриптов

Настраиваемые кнопки быстрого запуска из quickLaunch.json плюс произвольная команда: в фоне или с ожиданием вывода прямо в панель.

04

Питание

Выключение, перезагрузка, сон, блокировка экрана, выход из системы и отмена запланированного выключения. Каждое действие — через модалку подтверждения.

05

Авторизация

Логин и пароль (хранится только bcrypt-хэш), JWT-сессия с ограниченным сроком, rate-limit на вход и опциональный allowlist по IP-адресам.

06

Мобильный дашборд

Чистый JavaScript без сборки и фреймворков, тёмная тема, вёрстка под телефон и манифест PWA — панель ставится на домашний экран как приложение.

[ 03 ] как это работает

Три шага
от нуля до панели

  1. 01

    Сервер на ПК

    Node.js 18+, npm install, генерация пароля через npm run create-user и npm start. Панель слушает порт 3000 на самом компьютере.

  2. 02

    Приватная сеть

    Tailscale на ПК и на телефоне под одним аккаунтом. Компьютер получает адрес 100.x.x.x, трафик идёт через шифрованный туннель, проброс портов на роутере не нужен.

  3. 03

    Телефон в руках

    Открываете адрес в браузере, входите по логину и паролю — и управляете компьютером откуда угодно. Можно поставить сервер службой Windows, чтобы стартовал вместе с системой.

[ 04 ] безопасность

Панель умеет выключать ПК.
Значит, доступ — только ваш

01

Пароль хранится только как bcrypt-хэш — сам пароль не сохраняется нигде.

02

JWT-токен с ограниченным сроком жизни, по умолчанию 12 часов.

03

Rate-limit на вход: 8 попыток за 15 минут с одного IP.

04

Питание, запуск команд и завершение процессов требуют валидного токена.

05

Опциональный allowlist: панель отвечает только с разрешённых IP.

06

Рекомендуемый доступ — Tailscale или Cloudflare Tunnel, а не проброс порта в интернет.

[ 05 ] установка

Пять команд
в терминале

powershell — monitoring-pc 
git clone https://github.com/XsanX-Style/monitoring-pc
cd monitoring-pc
npm install
npm run create-user   # задать логин и пароль
npm start             # http://localhost:3000

Windows 10/11 · Node.js 18+ · на Linux и macOS работает с ограниченным набором команд питания
