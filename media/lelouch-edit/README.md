# XSANX × Лелуш — эдит с проектами

Эдит по Code Geass с вставками проектов (X-Style CRM, SMS Hub) и фрагментами автора.
Музыка, формат и весь материал по Лелушу взяты из исходного эдита-референса.

## Готовый файл

| Файл | Формат | Куда |
|---|---|---|
| `XSANX_lelouch_edit_1080x1080.mp4` | 1080×1080, 60 fps, 21.6 с | Instagram-лента, Telegram, VK |

## Ритм

Трек — 134.5 BPM, шаг бита `0.446 с`, фаза `0.430 с` (сетка получена перебором периода и фазы
по онсетам в `beats.py`). Почти все планы длятся 2 бита (0.892 с), вставки проектов и
фрагменты автора — 1 бит (0.446 с).

## Как пересобрать

Исходники (кадры) не лежат в git — они нарезаются из видео заново:

```bash
cd media/lelouch-edit/src
npm install
mkdir -p src/lelouch src/me src/proj

# 1. Лелуш — все кадры эдита-референса
ffmpeg -i /путь/к/референсу.mp4 -vf "fps=60,scale=1080:1080" -q:v 3 src/lelouch/l_%04d.jpg

# 2. Автор — лицо закрывается мозаикой, потом кадр обрезается в квадрат
python3 face-censor.py /путь/к/своему.mp4 face_out 16 0.78
ffmpeg -framerate 30 -i face_out/f_%04d.png \
  -vf "fps=60,crop=1080:1080:0:360,scale=1080:1080" -q:v 3 src/me/m_%04d.jpg

# 3. Проекты — куски из готовых роликов (по 0.5 с)
X=../../crm-edit/XSTYLE_CRM_edit_1080x1080.mp4
H=../../smshub-edit/SMSHUB_edit_1080x1920.mp4
ffmpeg -ss 3.50  -t 0.5 -i "$X" -vf "fps=60,scale=1080:1080" -q:v 3 src/proj/x1_%02d.jpg
ffmpeg -ss 5.32  -t 0.5 -i "$X" -vf "fps=60,scale=1080:1080" -q:v 3 src/proj/x2_%02d.jpg
ffmpeg -ss 6.75  -t 0.5 -i "$X" -vf "fps=60,scale=1080:1080" -q:v 3 src/proj/x3_%02d.jpg
ffmpeg -ss 10.35 -t 0.5 -i "$X" -vf "fps=60,scale=1080:1080" -q:v 3 src/proj/x4_%02d.jpg
ffmpeg -ss 5.95  -t 0.5 -i "$H" -vf "fps=60,crop=1080:1080:0:400,scale=1080:1080" -q:v 3 src/proj/s1_%02d.jpg
ffmpeg -ss 8.70  -t 0.5 -i "$H" -vf "fps=60,crop=1080:1080:0:420,scale=1080:1080" -q:v 3 src/proj/s2_%02d.jpg
ffmpeg -ss 10.25 -t 0.5 -i "$H" -vf "fps=60,crop=1080:1080:0:560,scale=1080:1080" -q:v 3 src/proj/s3_%02d.jpg
ffmpeg -ss 11.45 -t 0.5 -i "$H" -vf "fps=60,crop=1080:1080:0:420,scale=1080:1080" -q:v 3 src/proj/s4_%02d.jpg
```

Окна для вставок X-Style выбраны между вспышками на битах: если сдвинуть их на 0.2 с,
в кадр попадёт залитый цветом кадр вспышки.

Рендер и сборка:

```bash
node shoot.js preview 4.6 9.2 20.6   # отдельные кадры
node shoot.js all                    # 1297 кадров (~8 мин)
node shoot.js range 264 295          # перерисовать часть

REF=/путь/к/референсу.mp4
FX="eq=contrast=1.04:saturation=1.02,format=gbrp,split[a][b];\
[b]lutrgb=r='if(gt(val,188),val,0)':g='if(gt(val,188),val,0)':b='if(gt(val,188),val,0)',\
colorchannelmixer=.34:.33:.33:0:.34:.33:.33:0:.34:.33:.33,gblur=sigma=16,format=gbrp[bl];\
[a][bl]blend=all_mode=screen:all_opacity=0.20,format=yuv420p,noise=alls=6:allf=t+u[v]"

ffmpeg -framerate 60 -i frames/f_%05d.png -i "$REF" \
  -filter_complex "$FX;[1:a]afade=t=out:st=21.35:d=0.27[aud]" \
  -map "[v]" -map "[aud]" -shortest -c:v libx264 -crf 20 -preset slow -pix_fmt yuv420p -r 60 \
  -c:a aac -b:a 192k -ac 2 -movflags +faststart ../XSANX_lelouch_edit_1080x1080.mp4 -y
```

## Мозаика на лице

`src/face-censor.py` закрывает лицо полупрозрачной мозаикой:

```bash
python3 face-censor.py <видео> <папка-вывода> [размер клетки] [прозрачность]
python3 face-censor.py me.mp4 face_out 16 0.78     # клетка 16 px, мозаика на 78%
```

Лицо ищется каскадом Хаара в каждом кадре (фронтальный + профильный, включая зеркальный
проход), пропуски заполняются интерполяцией между соседними находками, а трек сглаживается
скользящим средним по 19 кадрам — поэтому патч не дёргается. Поверх лица кладётся размытие,
затем мозаика (`INTER_AREA` вниз, `INTER_NEAREST` вверх) и всё это смешивается с оригиналом
через мягкую эллиптическую маску, так что края не видно, а лицо остаётся угадываемым.

Клетка крупнее (24–32) и прозрачность ближе к 1.0 закроют лицо сильнее; меньше — слабее.

Готовый клип: `me_censored_1080x1920.mp4` (в этой же папке не хранится — пересобирается
командой выше).

## Что где править

`src/edit.html`, массив `CUTS` — это и есть монтажный лист. Поля:

- `t0`/`t1` — начало и конец плана (`B(k)` — k-й бит);
- `src` — источник: `l` (Лелуш), `m` (автор), `x1`…`s4` (вставки проектов);
- `ss` — с какой секунды источника играть, `sp` — скорость (0.55 — замедление);
- `z` — наезд `[от, до]`;
- `grade` — цветокор: `me` (контраст + обесцвечивание) или `proj` (подсветка интерфейсов);
- `lab`/`labc` — подпись на вставке и её цвет (`lime` — X-Style, `vio` — SMS Hub);
- `dark`, `fin` — затемнение и финальная карточка.

Сила тряски, вспышек, глитч-полос и хроматической аберрации — в конце `renderFrame()`.

Шрифты: Montserrat, Inter (Google Fonts, SIL OFL), в `src/fonts/`.
