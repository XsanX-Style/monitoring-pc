# XSANX CRM — промо-эдит

Короткий рекламный ролик про CRM-бот и CRM-сайт, смонтированный под трек из референса
(`IMG_9919.MP4`, Death Note edit): чёрно-белая картинка с красным акцентом, жёсткие резы по битам,
глитчи, зум-панчи, плёночное зерно.

## Как пересобрать

Кадры рисует Chromium по HTML-таймлайну, дальше всё склеивает ffmpeg.

```bash
cd media/crm-edit/src
npm install                 # playwright-core
node shoot.js preview 3.5 6.4   # отрисовать отдельные кадры в preview/
node shoot.js all               # все 666 кадров в frames/ (~2 мин)
```

Сборка (запускать из `src/`, `REF` — исходное видео, из него берётся звук):

```bash
REF=/путь/к/IMG_9919.MP4
FX="eq=contrast=1.05:saturation=0.96,format=gbrp,split[a][b];\
[b]lutrgb=r='if(gt(val,185),val,0)':g='if(gt(val,185),val,0)':b='if(gt(val,185),val,0)',\
colorchannelmixer=.34:.33:.33:0:.34:.33:.33:0:.34:.33:.33,gblur=sigma=18,format=gbrp[bl];\
[a][bl]blend=all_mode=screen:all_opacity=0.26,format=yuv420p,noise=alls=6:allf=t+u[v]"

ffmpeg -framerate 60 -i frames/f_%05d.png -i "$REF" \
  -filter_complex "$FX;[1:a]afade=t=out:st=10.29:d=0.18,apad=whole_dur=11.10[aud]" \
  -map "[v]" -map "[aud]" -c:v libx264 -crf 19 -preset slow -pix_fmt yuv420p -r 60 \
  -c:a aac -b:a 192k -ac 2 -movflags +faststart ../XSANX_CRM_edit_1080x1080.mp4 -y

# вертикаль 9:16
ffmpeg -i ../XSANX_CRM_edit_1080x1080.mp4 -vf "pad=1080:1920:0:420:black" \
  -c:v libx264 -crf 19 -preset slow -pix_fmt yuv420p -c:a copy \
  ../XSANX_CRM_edit_1080x1920_vertical.mp4 -y
```

## Что где править

Всё в `src/edit.html`:

- **Тексты и порядок кадров** — массив `CUES` (`t0`/`t1` в секундах, `B(k)` — номер бита).
- **Копирайт внутри интерфейсов** (сообщения бота, KPI, карточки сделок, пуши) — разметка сцен
  `#sc-bot`, `#sc-dash`, `#sc-kan`, `#sc-ph`, `#sc-split`.
- **Цвета** — переменные в `:root` (`--red`, `--ink`, `--paper`).
- **Сила тряски, вспышек и глитчей** — конец функции `renderFrame()`.
- **Бит-сетка** — константы `G0` (дроп) и `STEP` (шаг бита); при другой музыке пересчитать их
  и заново разложить `CUES`.

Цифры на дашборде (128 заявок, конверсия 34%, 1 240 000 ₽, +47%) — демонстрационные,
под реальные показатели их нужно заменить.

Шрифты: Oswald, Montserrat, Inter (Google Fonts, SIL Open Font License), лежат в `src/fonts/`.
